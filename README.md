# 🐦 پرنده خشمگین ۳بعدی — Angry Birds 3D

یک بازی مرورگری سه‌بعدی به سبک Angry Birds: با تیرکمان نشانه بگیر، سازه‌های چوبی/سنگی/یخی را
ویران کن و خوک‌های سبز را از پا دربیاور.

ساخته‌شده با **Three.js** (گرافیک) و **cannon-es** (فیزیک) — بدون هیچ فایل تصویری یا صوتی خارجی؛
همه‌ی بافت‌ها و صداها به‌صورت زنده در مرورگر ساخته می‌شوند.

## اجرا

```bash
npm install      # اختیاری — نسخه‌ی کتابخانه‌ها در vendor/ هم موجود است
npm start        # وب‌سرور روی http://localhost:8080
```

سپس مرورگر را روی <http://localhost:8080> باز کنید. (هر وب‌سرور استاتیک دیگری هم کار می‌کند؛
فقط باید پوشه‌ی پروژه را سرو کند، چون بازی از ES Modules استفاده می‌کند و با `file://` اجرا نمی‌شود.)

## نحوه‌ی بازی

- **شلیک:** پرنده را بگیر، به سمت پایین (و کمی چپ/راست برای هدف‌گیری) بکش و رها کن.
  هرچه بیشتر بکشی، شوت قوی‌تر می‌شود. نقطه‌های زرد مسیر پرواز را نشان می‌دهند.
- **دوربین:** کلیک راست (یا دکمه‌های گوشه‌ی صفحه) برای چرخش، چرخ ماوس برای زوم.
  جهت شلیک به دوربین وابسته نیست.
- **هدف:** همه‌ی خوک‌ها را نابود کن. چوب سریع می‌شکند، یخ شکننده است و سنگ مقاومت زیادی دارد.
- **امتیاز:** هر بلوک و هر خوک امتیاز دارد؛ هر پرنده‌ی استفاده‌نشده ۱۰۰۰ امتیاز پاداش می‌گیرد.
- **میان‌بر:** `R` شروع دوباره، `Esc` منو، کلیدهای جهت‌دار چرخش دوربین.

## ویژگی‌ها

- ۴ مرحله با سازه‌های متفاوت (کلبه چوبی، برج دوقلو، قلعه‌ی سنگی، برج بلند)
- فیزیک واقعی تخریب: بلوک‌ها بر اساس شدت ضربه آسیب می‌بینند و می‌شکنند
- خوک‌ها با ضربه‌ی مستقیم یا سقوط از ارتفاع از بین می‌روند
- دوربین سه‌بعدی، سایه‌های نرم، ذرات تخریب، لرزش دوربین
- افکت صوتی کامل با WebAudio (بدون فایل صوتی)
- رابط فارسی و راست‌به‌چپ، ذخیره‌ی پیشرفت و ستاره‌ها در `localStorage`
- واکنش‌گرا: در حالت عمودی گوشی، قاب دوربین خودکار تنظیم می‌شود

## ساختار پروژه

```
index.html          رابط کاربری و صفحه‌ی بازی
styles.css          استایل رابط (فارسی/RTL)
server.mjs          وب‌سرور استاتیک کوچک بدون وابستگی
src/game.js         چرخه‌ی بازی، ورودی‌ها، دوربین و منطق مراحل
src/physics.js      دنیای cannon-es، آسیب بلوک‌ها و خوک‌ها، امتیاز
src/scene.js        صحنه، محیط، تیرکمان، مش‌ها، ذرات و مسیر پیش‌بینی
src/levels.js       داده‌ی چهار مرحله
src/audio.js        ساخت صداها با WebAudio
vendor/             سه‌بعدی و فیزیک به‌صورت محلی (بدون CDN)
tools/              تست‌های سرسری بدون مرورگر
```

## تست

```bash
npm run test:physics   # پایداری سازه‌ها و اثر شلیک‌ها
npm run test:scene     # ساخت مش‌ها و مسیر پیش‌بینی بدون مرورگر
```

## English

A 3D Angry-Birds-style slingshot game built with Three.js + cannon-es. Drag the bird back
and release, knock down wood/stone/ice structures, and pop every green pig. All textures and
sound effects are generated at runtime. Run `npm start` and open http://localhost:8080.
