# 🐦 پرندگان خشمگین سه‌بعدی — Angry Birds 3D

یک بازی کامل و سه‌بعدی شبیه «انگری بردز» با گرافیک ساختگی (Three.js) و فیزیک واقعی (cannon-es).
منجنیق را بکش، پرنده‌ها را رها کن و قلعه‌ی خوک‌های بدجنس را ویران کن!

![three.js](https://img.shields.io/badge/three.js-r187-black?logo=threedotjs) ![cannon-es](https://img.shields.io/badge/physics-cannon--es-blue) ![vite](https://img.shields.io/badge/build-vite-purple)

## ✨ ویژگی‌ها

- 🌍 **دنیای سه‌بعدی کامل**: آسمان گرادیان با خورشید، ابرهای متحرک، تپه‌ها، درخت‌ها، گل‌ها و صخره‌ها — همه با تکسچرهای رویه‌ای (Canvas) ساخته می‌شوند، بدون نیاز به فایل‌های بیرونی
- 🪨 **فیزیک واقعی** با cannon-es: بلوک‌های چوب، یخ و سنگ با جرم و استحکام واقعی، فروپاشی زنجیره‌ای سازه‌ها
- 🐦 **سه پرنده با توانایی‌های متفاوت**:
  - **قرمز** — همه‌کاره و قدرتمند
  - **زرد** — در هوا کلیک کن تا مثل موشک شتاب بگیرد
  - **سیاه** — در هوا کلیک کن یا مستقیم برخورد کن تا منفجر شود
- 🐷 **خوک‌ها در سه اندازه** (کوچک / معمولی / پادشاه با تاج طلایی!)
- 🧨 **دینامیت زنجیره‌ای** — با برخورد محکم منفجر می‌شود و همه‌چیز را با خود می‌برد
- 🎯 **۵ مرحله** با دشواری فزاینده، امتیاز، ستاره‌بندی و باز شدن تدریجی مراحل (ذخیره در localStorage)
- 🎵 **صدای کاملاً ساختگی** با Web Audio API (هیچ فایل صوتی‌ای دانلود نمی‌شود): پرتاب، خرد شدن چوب/یخ/سنگ، پاپ شدن خوک، انفجار، فن‌فر و موسیقی متن ملایم
- ✨ **جلوه‌های بصری**: پرهای پرنده، چیپس چوب و یخ، موج ضربه‌ای انفجار، لرزش دوربین، امتیازهای شناور
- 🇮🇷 رابط کاملاً **فارسی و راست‌به‌چپ** با فونت وزیرمتن و اعداد فارسی
- 📱 لمسی و ماوس — روی موبایل هم کار می‌کند

## 🎮 نحوه‌ی بازی

1. **کشیدن**: پرنده را با ماوس یا انگشت بگیر و به عقب بکش؛ نقاط سفید مسیر پرواز را پیش‌بینی می‌کنند
2. **رها کردن**: پرنده شلیک می‌شود!
3. **توانایی**: در هوا کلیک/ضربه بزن تا توانایی پرنده فعال شود
4. با کم‌ترین پرنده‌ی ممکن همه‌ی خوک‌ها را نابود کن تا ۳ ستاره بگیری 🌟

## 🚀 اجرا

```bash
npm install
npm run dev      # http://localhost:5173
```

برای بیلد نهایی:

```bash
npm run build    # خروجی در dist/
npm run preview  # پیش‌نمایش بیلد
```

## ⌨️ میان‌برهای صفحه‌کلید

| کلید | کار |
|------|-----|
| `R` | شروع دوباره‌ی مرحله |
| `Esc` | مکث |

## 🕹️ کنترل دوربین

- **چرخش**: کشیدن روی فضای خالی (به جز خود پرنده)
- **زوم**: اسکرول / پینچ
- حین پرواز، دوربین به نرمی پرنده را دنبال می‌کند و در پایان به نمای کلی برمی‌گردد

## 🧩 ساختار پروژه

```
src/
├── main.js       # رابط کاربری، ذخیرهٔ پیشرفت، اتصال دکمه‌ها
├── game.js       # حلقهٔ بازی، فیزیک، برخورد و آسیب، انفجار، دوربین
├── builders.js   # کارخانهٔ مش‌ها (پرندہ، خوک، بلوک، منجنیق، دکور)
├── levels.js     # تعریف مراحل و ثابت‌های بازی
├── particles.js  # سیستم ذرات با ShaderMaterial
├── audio.js      # موتور صوتی Web Audio API
└── style.css     # استایل‌های رابط کاربری (RTL)
```
