# پرندگان خشمگین — نبرد سه‌بعدی

یک بازی مرورگری با طراحی سه‌بعدی (Three.js) و فیزیک برخورد و تخریب (cannon-es).

```sh
npm ci
npm run dev
```

پرندهٔ روی فلاخن را با ماوس یا لمس به عقب بکشید و رها کنید. خط نقطه‌چین مسیر تقریبی پرتاب را نشان می‌دهد. در هر مرحله چهار پرنده دارید. با زدن همهٔ خوک‌ها مرحلهٔ بعد باز می‌شود. دکمهٔ ↻ یا کلید R مرحله را از نو شروع می‌کند.

برای ساخت نسخهٔ قابل انتشار: `npm run build`.
