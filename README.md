# 🐦 پرندگان خشمگین — نبرد سه‌بعدی | Angry Birds 3D

یک بازی مرورگری با طراحی سه‌بعدی (Three.js) و فیزیک برخورد و تخریب (cannon-es).
نسخهٔ اصلی: **«پرندگان خشمگین سه‌بعدی»** — دنیای کامل سه‌بعدی با ۵ مرحله.
نسخهٔ کلاسیک: **«درهٔ آفتاب»** — نسخهٔ جمع‌وجورِ PR #1 (دوربین Orthographic، پالت آفتاب‌غروبی) در [classic.html](classic.html).

![three.js](https://img.shields.io/badge/three.js-r187-black?logo=threedotjs) ![cannon-es](https://img.shields.io/badge/physics-cannon--es-blue) ![vite](https://img.shields.io/badge/build-vite-purple)

## ✨ ویژگی‌ها

- 🌍 **دنیای سه‌بعدی کامل**: آسمان گرادیان با خورشید، ابرهای متحرک، تپه‌ها، درخت‌ها، گل‌ها و صخره‌ها — با تکسچرهای رویه‌ای (Canvas)، بدون نیاز به فایل‌های بیرونی
- 🪨 **فیزیک واقعی** با cannon-es: بلوک‌های چوب، یخ و سنگ با جرم و استحکام واقعی، فروپاشی زنجیره‌ای سازه‌ها
- 🐦 **سه پرنده با توانایی در هوا**: قرمز (همه‌کاره) · زرد (شتاب موشکی) · سیاه (انفجار مهیب)
- 🐷 خوک‌ها در سه سایز + پادشاه با تاج طلایی · 🧨 دینامیت با انفجار زنجیره‌ای
- 🗺️ **۵ مرحله** با دشواری فزاینده، امتیاز، ★★★ برای هر مرحله و باز شدن تدریجی مراحل (ذخیره در localStorage)
- 🎵 **صدای کاملاً ساختگی** با Web Audio API (هیچ فایل صوتی‌ای دانلود نمی‌شود) + موسیقی متن ملایم
- ✨ جلوه‌ها: پر پرنده، چیپس چوب/یخ، موج انفجار، لرزش دوربین، امتیازهای شناور
- 🇮🇷 رابط کاملاً **فارسی و راست‌به‌چپ** با فونت وزیرمتن و اعداد فارسی
- 📱 لمسی و ماوس — روی موبایل هم کار می‌کند

## 🎮 نحوه‌ی بازی

پرنده‌ی روی فلاخن را با ماوس یا لمس به عقب بکشید و رها کنید. نقاط سفید مسیر تقریبی پرتاب را نشان می‌دهند. در هر مرحله چند پرنده دارید؛ با زدن همهٔ خوک‌ها مرحلهٔ بعد باز می‌شود.

1. **کشیدن**: پرنده را بگیر و عقب بکش (نقطه‌چین = مسیر تقریبی)
2. **رها کردن**: پرنده شلیک می‌شود!
3. **توانایی**: در هوا کلیک/ضربه بزن — زردها شتاب می‌گیرند و سیاه‌ها منفجر می‌شوند
4. با کم‌ترین پرنده‌ی ممکن همه‌ی خوک‌ها را نابود کن تا ۳ ستاره بگیری 🌟

## 🚀 اجرا

```bash
npm ci
npm run dev      # http://localhost:5173
```

برای ساخت نسخهٔ قابل انتشار:

```bash
npm run build    # خروجی در dist/ (شامل index.html و classic.html)
npm run preview  # پیش‌نمایش بیلد
```

## 🕹️ حالت کلاسیک (درهٔ آفتاب)

نسخهٔ کوتاه‌تر و هنری‌تر بازی (کارِ مستقلِ پی‌ریکوئست #1) به همان شکل اصلی در `classic.html` نگه‌داری می‌شود — از لینک «نسخهٔ کلاسیک» در فوتر منوی اصلی هم در دسترس است.

## ⌨️ میان‌برها

| کلید | کار |
|------|-----|
| `R` | شروع دوباره‌ی مرحله |
| `Esc` | مکث |

چرخش دوربین با کشیدن فضای خالی، زوم با اسکرول/پینچ؛ حین پرواز دوربین پرنده را دنبال می‌کند.

## 🧩 ساختار پروژه

```
index.html      # نسخهٔ اصلی (پرندگان خشمگین سه‌بعدی)
classic.html    # نسخهٔ کلاسیک (درهٔ آفتاب، PR #1)
src.js          # منطق نسخهٔ کلاسیک
style.css       # استایل نسخهٔ کلاسیک
src/
├── main.js       # رابط کاربری، ذخیرهٔ پیشرفت، اتصال دکمه‌ها
├── game.js       # حلقهٔ بازی، فیزیک، برخورد و آسیب، انفجار، دوربین
├── builders.js   # کارخانهٔ مش‌ها (پرندہ، خوک، بلوک، منجنیق، دکور)
├── levels.js     # تعریف مراحل و ثابت‌های بازی
├── particles.js  # سیستم ذرات با ShaderMaterial
├── audio.js      # موتور صوتی Web Audio API
└── style.css     # استایل‌های رابط کاربری نسخهٔ اصلی (RTL)
scripts/smoke.mjs # تست دود بدون مرورگر
```
